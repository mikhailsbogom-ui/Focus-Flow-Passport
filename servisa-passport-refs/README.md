# SERVISA Professional Digital Passport — Visual References

Набор референсных UI-изображений и фото поставщиков для другой нейросети / пайплайна вёрстки.

Репозиторий: https://github.com/mikhailsbogom-ui/Focus-Flow-Passport
Папка: `servisa-passport-refs/`

## Структура
- `generated/` — UI-экраны паспорта
- `source-spec/` — кадры из продуктовых спецификаций (паспорт + профиль поставщика)
- `suppliers/` — фото поставщиков услуг (свет, звук, LED, генераторы, кейтеринг, логистика, декор, монтаж)
- `manifest.json` — индекс для другой модели

## Visual tokens
- Accent: #FF6A2A
- Dark charcoal navigation + light workspace
- Russian UI
- Evidence before claims, public != private, explainable trust
